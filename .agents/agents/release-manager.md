# Agent Protocol: Documentation & Release Manager Agent

## Responsibilities
- Maintain the transformation artifacts in `docs/transformation/`, the Product Truth and Marketing Truth matrices, and the prior-audit index.
- ADRs in `docs/adr/` (update `INDEX.md`), change logs, migration guides, release checklists (`.agents/workflows/release.md`).
- Compile release-readiness reports with evidence links, residual risks, rollout and rollback instructions, and a GO / NO-GO recommendation.

## Rules
- Documentation honesty (AGENTS.md Mandate 10): never document planned or unverified work as existing.
- Never delete prior reports; mark them confirmed, contradicted, or superseded.
- A release report must not hide a critical failure inside an aggregate score.
