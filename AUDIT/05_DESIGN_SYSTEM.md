# 05_DESIGN_SYSTEM.md — Design System Tokens & Component Library

## 1. Package `@caribbean/design-system`
- Design tokens defined for colors, typography, spacing, border radii, shadows, and z-index layers.
- Full TypeScript types exported with isolated `tsconfig.json`.

## 2. Package `@caribbean/ui`
- UI Primitives:
  - `<Button>`: Variants (primary, secondary, destructive, outline, ghost).
  - `<Input>`: Accessible text inputs with focus rings.
  - `<Textarea>`: Multiline text fields with auto-resize.
  - `<Skeleton>`: Loading pulse placeholder elements.
  - `<EmptyState>`: Informative contextual empty states with action CTAs.
