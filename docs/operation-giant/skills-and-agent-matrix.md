## 4. Governance & Quality Gates

Each agent must operate under the inviolable rules of TUKUBI:
1. **Rule 1: Preserve Existing Functionality** — No removing or breaking working features.
2. **Rule 2: Zero Mock Data** — Honest empty states; no synthetic users or counts in production.
3. **Rule 3: Double-Entry Financial Safety** — Strictly immutable ledger transactions; zero mutable balance column updates.
4. **Rule 4: Zero Secrets Committed** — All API keys and secrets stay in environment files.
5. **Rule 5: No Unsupported Claims** — Evidence before assertions; all claims verified with test output or benchmarks.
6. **Rule 6: Work in Controlled Phases** — Systematic audit, implementation, and certification.
7. **Rule 7: Never Sacrifice Reliability for Speed** — Security and data integrity always take precedence.
