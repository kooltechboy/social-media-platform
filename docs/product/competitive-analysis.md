# Competitive Analysis — TUKUBI

## 1. Positioning
We are not cloning any incumbent. Differentiation = **Caribbean Graph** (people + culture + places + businesses + diaspora) that no global platform models natively.

| Competitor | Strength We Take | Weakness We Exploit |
| :--- | :--- | :--- |
| **Facebook** | Groups, events, network effects | Generic feed, declining creator trust, weak cultural/geo identity, ad-load fatigue |
| **Instagram** | Visual culture, reels, creator tools | No community depth, discovery favors mega-creators, Caribbean content buried |
| **X** | Real-time discourse, text | Toxicity, weak communities, no commerce/creator economics for small markets |
| **TikTok** | Short-video discovery engine | Best-in-class recsys we can't match initially — compete on cultural relevance instead; no identity/community layer |
| **YouTube** | Long-form + monetization maturity | Heavyweight for casual creators; poor community/diaspora grouping |
| **Twitch** | Live + gifting economy | Gaming-centric; no Caribbean cultural context |
| **Discord** | Community chat depth | Niche UX, discovery-hostile, no public identity layer |
| **Reddit** | Community structure, moderation culture | Anonymity-first; no creator economy, no business layer |
| **LinkedIn** | Professional graph | Caribbean professionals underserved; no cultural/community dimension |
| **Patreon/Substack** | Creator monetization | No discovery; creators bring their own audience |
| **WhatsApp** (indirect) | Diaspora group-chat gravity | Not a platform: no discovery, no creator economy, no business tools — our communities/events must be compelling enough to graduate those groups |

## 2. Our Defensibility
1. **Caribbean Graph** — proprietary identity/relationship data layer.
2. **Network density by geography** — DR-first launch strategy (PRODUCT-REQUIREMENTS.md §7) creates local monopolies of attention.
3. **Creator + business economics in one ecosystem** — SpotPay unifies tips, subs, tickets, marketplace, payouts across fragmented Caribbean payment rails.
4. **Multilingual by design** — en/es/fr/ht/nl/pap at launch vs. English-first incumbents.

## 3. Risks
- Incumbent "Caribbean mode" imitation → mitigated by graph depth + creator/business lock-in economics.
- Cold-start → recruit creators/businesses/communities before mass acquisition.
- Payment complexity across jurisdictions → `psp_capabilities` matrix + PSP abstraction.
