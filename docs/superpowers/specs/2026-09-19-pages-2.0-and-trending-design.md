# Pages 2.0 & Real-Time Trending Topics Specification

**Author:** Tukubi Principal Engineering Architecture Team  
**Date:** September 19, 2026  
**Status:** Approved for Implementation (Approach B)

## 1. Overview & Vision

TUKUBI ("The Caribbean Connected") elevates Pages into a universal first-class platform entity—comparable in capability to Facebook Pages, yet tailored to Caribbean Futurism and diaspora unity.
Alongside Universal Pages, the platform enforces a **Zero Mock Data** mandate for Trending Topics: eradicating all hard-coded fallback trends, fake counts, and seeded hashtags in favor of real-time activity computation and honest empty states.

---

## 2. Core Architectural Pillars

### A. Universal Page Model
- Any legitimate individual creator, company, brand, media outlet, diaspora association, institution, NGO, school, sports team, religious body, or event organization can create and administer a Page.
- Users can own and manage multiple Pages.
- An extensible 12-group taxonomy (`public.page_categories`) categorizes Pages without restricting their fundamental capabilities (posting, media, followers, messaging, analytics).

### B. Role-Based Administration (RBAC)
- Backed by `public.page_roles`:
  - **Owner**: Full lifecycle control, ownership transfer, team administration, deactivation, deletion.
  - **Administrator**: Management permissions, role assignment (below owner), settings, post publishing.
  - **Editor / Content Manager**: Content creation, post publishing, media management.
  - **Moderator**: Review management, community interactions, comment moderation.
  - **Analyst**: Read-only view of real follower metrics and performance.

### C. Decoupled Page Followers & Activity
- `public.page_followers` stores authentic follower relationships `(page_id, user_id)`.
- Follow/unfollow operates atomically via backend server actions and database RPC.
- Follower metrics reflect actual database rows.

### D. Page Post Publishing
- `public.posts` gains `page_id REFERENCES public.businesses(id) ON DELETE CASCADE`.
- Page owners, administrators, and editors can publish posts on behalf of the Page.
- Posts appear on Page profiles, feeds, and exploration with proper attribution.

### E. Symmetric Page Lifecycle
- **Create**: 6-step guided wizard with category search, identity, geography, contact, and specialized details.
- **Manage**: Dashboard with overview, profile editing, team management, posts, and analytics.
- **Deactivate**: Pauses public discovery while preserving all data, enabling instant owner reactivation.
- **Delete**: Owner-only permanent cascading deletion with explicit confirmation.

### F. Real-Time Zero-Mock Trending Engine
- Trending signals computed dynamically from actual posts (`cultural_tags`, hashtags, reaction velocity).
- Eradication of hardcoded arrays in `FeedsRail`, `HomeRail`, and everywhere else.
- If real activity is insufficient (< 1 trend), renders the authentic empty state:
  *"Trending topics will appear here as the TUKUBI community grows."*

## 3. Database Schema Blueprint (`00094_universal_pages_roles_and_trending.sql`)

```sql
-- 1. Page Categories
CREATE TABLE public.page_categories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    group_key VARCHAR(50) NOT NULL,
    group_name VARCHAR(100) NOT NULL,
    slug VARCHAR(80) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    icon_name VARCHAR(50) DEFAULT 'Building2',
    is_active BOOLEAN DEFAULT true NOT NULL,
    created_at TIMESTAMPTZ DEFAULT now() NOT NULL
);

-- 2. Page Extensions on public.businesses
ALTER TABLE public.businesses
    ADD COLUMN IF NOT EXISTS page_type VARCHAR(40) DEFAULT 'universal',
    ADD COLUMN IF NOT EXISTS category_id UUID REFERENCES public.page_categories(id),
    ADD COLUMN IF NOT EXISTS is_deactivated BOOLEAN DEFAULT false,
    ADD COLUMN IF NOT EXISTS deactivated_at TIMESTAMPTZ,
    ADD COLUMN IF NOT EXISTS custom_settings JSONB DEFAULT '{}'::jsonb;

-- 3. Page Roles
CREATE TABLE public.page_roles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    page_id UUID REFERENCES public.businesses(id) ON DELETE CASCADE NOT NULL,
    user_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE NOT NULL,
    role VARCHAR(20) CHECK (role IN ('owner', 'admin', 'editor', 'moderator', 'analyst')) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT now() NOT NULL,
    CONSTRAINT uq_page_roles UNIQUE (page_id, user_id)
);

-- 4. Page Followers
CREATE TABLE public.page_followers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    page_id UUID REFERENCES public.businesses(id) ON DELETE CASCADE NOT NULL,
    user_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT now() NOT NULL,
    CONSTRAINT uq_page_followers UNIQUE (page_id, user_id)
);

-- 5. Post Page Attribution
ALTER TABLE public.posts
    ADD COLUMN IF NOT EXISTS page_id UUID REFERENCES public.businesses(id) ON DELETE CASCADE;
```
