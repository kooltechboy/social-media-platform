# TUKUBI Feature Preservation Register (`TUKUBI_FEATURE_PRESERVATION_REGISTER.md`)

**Program:** `TUKUBI-RTP-001` (Phase 1 — Forensic Audit & Baseline Verification)  
**Date:** 2026-10-12  
**Mandate:** Zero silent feature deletion. Every existing route, package, and capability across all 6 apps and 25 packages is inventoried, classified, and assigned an explicit disposition (`PRESERVE`, `REFACTOR`, `REPAIR`, `CONSOLIDATE`, or `FREEZE EXPANSION`).

## 2. Redirect & Alias Preservation Table

All 13 redirect routes in `apps/web/src/app` are preserved to prevent broken bookmarks or external deep links:
- `/home` $\to$ `/`
- `/feeds` $\to$ `/?tab=`
- `/feeds/[tab]` $\to$ `/?tab=[tab]`
- `/people` $\to$ `/friends`
- `/members` $\to$ `/friends`
- `/profile` $\to$ `/profile/[username]` (or `/login?next=/profile`)
- `/messages/[username]` $\to$ `/messages?u=[username]`
- `/explore/diaspora` $\to$ `/diaspora` $\to$ `/caribbean`
- `/podcast` $\to$ `/podcasts`
- `/moderation/signup` $\to$ `/moderator/signup`
